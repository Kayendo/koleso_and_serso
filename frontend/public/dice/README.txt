Опциональные текстуры для 3D-броска кубиков
==========================================

Положите сюда файлы — игра подхватит их автоматически:

  felt.jpg   — текстура сукна (рекомендуется 1024×1024, вид сверху)
  felt.png   — то же, если нет jpg

Если файла нет, используется встроенный зелёный материал.

  Dice.glb   — 3D-модель кубика (подхватывается автоматически)
               Если файла нет — процедурный кубик с точками.
